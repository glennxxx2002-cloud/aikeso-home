# AiKESO@Home 院外病人端（GitHub Pages）

- `pt.html`：病人端頁面。病人連結格式：`pt.html?bed=V01`（床號已帶入，病人只需輸入密碼）。
- 資料透過 Google Apps Script 後端 API 與院內的戰情室／醫師端／護理端共用，不需要 Claude 帳號。
- 啟用方式：Settings → Pages → Source: Deploy from a branch → main / (root) → Save。
- 網址：`https://glennxxx2002-cloud.github.io/aikeso-home/pt.html?bed=V01`

所有病人皆為虛構示範資料。
